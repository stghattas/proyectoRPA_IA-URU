# 🤖 RPA en Python: Análisis de Ventas y Notificaciones por WhatsApp

Este proyecto implementa un **Robotic Process Automation (RPA)** utilizando Python. El objetivo del bot es extraer datos de ventas desde un archivo Excel local, realizar transformaciones, calcular métricas financieras clave, generar un dashboard visual y automatizar el envío de un reporte ejecutivo a un número de WhatsApp usando la API de Twilio.

## 🚀 Competencias Aplicadas
1. Automatización de procesos (RPA).
2. Manipulación y análisis de datos con `Pandas`.
3. Visualización de datos (Dashboards) con `Matplotlib`.
4. Integración con APIs de terceros (`Twilio`).

## 🛠 Herramientas Utilizadas
* **Python 3.x**
* **Pandas & Openpyxl** (Lectura de Excel)
* **Matplotlib** (Gráficos)
* **Twilio** (WhatsApp API)
